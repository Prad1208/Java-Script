# JavaScript Mini Projects

A collection of small, beginner-to-intermediate projects built with **HTML, CSS and vanilla JavaScript** to practice DOM manipulation, event handling, state management, and working with APIs. Each project lives in its own folder and runs directly in the browser, with no build step or dependencies.

## Projects

| # | Project | What it does | Concepts practiced |
|---|---------|--------------|--------------------|
| 1 | [Calculator](./calculator)                |  Basic arithmetic calculator with a clickable keypad|DOM events, expression handling!!
| 2 | [Color Catcher](./colorcatcher)           |  Color-based catching game | Game loop,randomness,scoring, AMAZING PROJECT!!
| 3 | [Currency Converter](./currencyconverter) |  Converts an amount between currencies using exchange rates | `fetch` API, async/await, error handling!!
| 4 | [Movie Predictor](./moviepredictor)       |  Suggests or predicts a movie based on user input | Arrays, conditionals, DOM updates!!
| 5 | [Password Generator](./password_generator)|  Generates random passwords with selectable options | Randomization, string handling, clipboard concepts learned!!
| 6 | [Shape Game](./shapegame)                 |  Interactive game built around shapes | Events, state, game logic !!
| 7 | [Traffic Light](./trafficlight)           |  Traffic light simulation that cycles through signals |  CSS classes !!
| 8 | [Tic Tac Toe](./tictactoe)                |  Two-player Tic Tac Toe with win and draw detection | 2D logic, state, event delegation !!
| 9 | [To-Do List](./todolist)                  |  Add, complete and delete tasks | Array state, DOM rendering, event handling, Callbacks, CallBack Hell !!

## Tech Stack
- **HTML5** for structure
- **CSS3** for styling and layout
- **JavaScript (ES6+)** for logic and interactivity

## Running Locally
```bash
# For cloning the repository
git clone https://github.com/Prad1208/Java-Script.git
# Open any project folder,for ex.:
cd Java-Script/tictactoe

# Open index.html in your browser
```

You can also use the **Live Server** extension in VS Code for auto-reload.

## What I Learned
- Selecting and updating elements with the DOM
- Handling user input with event listeners
- Managing application state without a framework
- Fetching and displaying data from public APIs
- Structuring small projects cleanly in separate folders
